FDE · Betterware · Betty mejorada 03 / 09 La propuesta

Programa Insiders · Betty mejorada

Un piloto cerrado con 15-25 distribuidoras aliadas durante dos semanas antes del rollout general. Mínima exposición, máxima evidencia.

Framing clave: Betty mejorada no es Betty 2.0. Betty sigue siendo Betty — la misma persona, el mismo tono, el mismo canal. Lo que cambia es la implementación técnica por detrás: menos fallos, respuestas más claras, mayor fiabilidad.

En una línea

  • Piloto cerrado del 16 al 30 de octubre con 15-25 distribuidoras aliadas (super usuarias, perfiles representativos).
  • Alcance explícito: los flujos operativos actuales (saldos, pedidos, puntos, altas, pagos, tickets, reset, FAQ, escalación). No features nuevas.
  • Reconocimiento y voz privilegiada: las piloto se convierten en embajadoras del cambio.
  • Reversible atómicamente: kill-switch global en Custom Metadata + V40 intacto como fallback.
  • Evidencia dura antes del rollout general: NPS cualitativo, intents validados, bugs resueltos antes de abrir al 100%.

FDE · Betterware · Betty mejorada 05 / 09 Arquitectura técnica

Routing al nacer la MessagingSession

Al crearse una MessagingSession, un Flow nuevo (nuestro) decide a qué agente va. Sin dependencia del código del Partner. Sin turnos extra visibles. 100% reversible desde Custom Metadata.

  WhatsApp inbound
         │
         ▼
  MessagingSession.create (RecordAfterSave)
         │
         ▼
  ┌─────────────────────────────────────────────────┐
  │  BW_FDE_RouteAgent  (Flow autolaunched, FDE)    │
  │                                                  │
  │  1. BW_FDE_RoutingDecision (Apex invocable)     │
  │     • Lee FDE_Pilot_Config__mdt.Default         │
  │     • Si kill-switch OFF  → V40_LEGACY          │
  │     • Si phone ∈ whitelist → FDE_PILOT_WHITELIST│
  │     • Si hash(phone)%100 < rollout → FDE_PILOT_ROLLOUT │
  │     • Sino → V40_LEGACY                         │
  │                                                  │
  │  2. Update MessagingSession.AgentVersion__c     │
  │  3. Transfer-to-Bot al destino decidido         │
  └─────────────────────────────────────────────────┘
         │
         ├──── FDE_PILOT_* ──→  FDE_BW_Service_Agent (nuevo)
         │
         └──── V40_LEGACY ──→   BW_AGENT_N (como hoy)

  • MessagingSession.AgentVersion__c · persiste decisión para A/B analytics
